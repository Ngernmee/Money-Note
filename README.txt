Money Note - Vercel edition

วิธี deploy:
1. แตกไฟล์ ZIP นี้
2. ถ้าต้องการให้เว็บมีเพลงติดมาด้วย ให้นำไฟล์ MP3 ของคุณใส่ในโฟลเดอร์ music
   และตั้งชื่อไฟล์เป็น background.mp3
3. เข้า Vercel แล้วเลือก Add New -> Project -> อัปโหลด/Import โปรเจกต์นี้จาก Git
   หรือใช้ Vercel CLI ในโฟลเดอร์โปรเจกต์: vercel --prod
4. Framework Preset เลือก Other และปล่อย Build Command ว่างได้
5. เปิด URL ที่ Vercel ให้ แล้วกดปุ่มเล่นเพลง

การเพิ่มเพลง:
- เลือกไฟล์ MP3 จากปุ่ม “เลือก MP3” ได้ในหน้าเว็บ เพลงที่เลือกจะถูกเก็บใน IndexedDB
  ของเบราว์เซอร์และอุปกรณ์นั้น เพื่อเปิดใช้ซ้ำในครั้งถัดไป
- ถ้าต้องการให้ทุกคนที่เข้าเว็บได้ยินเพลงเดียวกัน ให้วางไฟล์ไว้ที่ music/background.mp3
  ก่อน deploy (ผู้เข้าชมยังต้องกดเล่นเอง เพราะเบราว์เซอร์ส่วนใหญ่บล็อก autoplay)

การบันทึกข้อมูล:
- รายการและโปรไฟล์เก็บใน LocalStorage ของเบราว์เซอร์เครื่องนั้น
- เว็บเวอร์ชันนี้ยังไม่ซิงก์ข้อมูลข้ามอุปกรณ์/ข้ามเบราว์เซอร์
- อย่าล้าง Site Data หากต้องการเก็บข้อมูลไว้
